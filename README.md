CV HTML Assignment
📄 Project Overview
This repository contains a basic HTML-based CV (Curriculum Vitae) developed as part of a web development assignment. The purpose of this project is to demonstrate a foundational understanding of HTML structure and formatting by creating a clean, well-organized personal resume using only HTML.

It is designed for educational use, especially for beginners who are learning how to structure content semantically using core HTML tags.

📌 Key Features
Pure HTML (no CSS or JavaScript)

Clean, readable code structure

Beginner-friendly

Easy to modify for personal use

📚 Sections Included
The CV includes the following key sections:

✅ Objective

🧍 Personal Information

🎓 Education

📖 Favourite Books
